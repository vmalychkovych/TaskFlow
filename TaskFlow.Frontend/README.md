# TaskFlow Frontend

Next.js frontend shell for the TaskFlow API.

## Quick start

1. Copy `.env.example` to `.env.local`
2. Install dependencies with your package manager:
   - `pnpm install`
   - or `npm install`
3. Start the dev server:
   - `pnpm dev`
   - or `npm run dev`

The app expects the ASP.NET API to be available at `NEXT_PUBLIC_API_URL`.
